CREATIX STUDIO WEBSITE

This folder contains the complete Creatix Studio website and its image assets.

Open index.html in a browser to preview the site. Keep index.html and all PNG/WebP files together in this folder so the logo, avatar, and browser-tab icon load correctly.

The homepage includes:
- About, services, process, portfolio, client reviews, and contact sections
- The new “More From Creatix Studio” section featuring Brandora AI, Growth Auditor, and More Projects in Process

Brandora AI is presented as a project card. Growth Auditor links to https://growthauditor.vercel.app/ and opens in a new browser tab. The separate project folders remain separate because Brandora AI needs its own server/API configuration.

Files:
- index.html — complete website
- favicon.png — browser-tab icon
- logo-mark.png — Creatix Studio mark
- cs avatar.png — About section avatar
- Creatix Studio Monogram Logo.png and logo-transparent.png — full logo artwork
- team-member.webp — additional image asset
